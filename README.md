# 📋 Marine Cargo Claims Case Management Dashboard

> An automated Microsoft Excel dashboard for managing, tracking, and monitoring marine cargo insurance claims throughout the claim lifecycle.

![Dashboard Preview](dashboard-preview.png)

---

# 📌 Overview

This project demonstrates the development of an operational case management dashboard using Microsoft Excel for marine cargo insurance claims.

The dashboard centralizes claim information, monitors operational activities, tracks claim progress, and provides management with real-time visibility into claim handling performance.

The solution was designed to improve operational efficiency by reducing manual monitoring and providing a structured overview of active claim cases.

> **Note:** This repository is shared for portfolio purposes only. All confidential business information has been removed or anonymized.

---

# 🎯 Business Problem

Managing multiple insurance claim files manually can be challenging, particularly when tracking:

- Active claim cases
- Outstanding reports
- Case ageing
- Monthly workload
- Claim status
- SLA compliance

Without a centralized dashboard, monitoring operational performance becomes time-consuming and prone to oversight.

---

# 💡 Solution

Developed an automated Microsoft Excel dashboard that enables users to:

- Track active claim cases
- Monitor claim progress
- Analyze case ageing
- Measure operational workload
- Monitor report compliance
- Generate summary dashboards automatically
